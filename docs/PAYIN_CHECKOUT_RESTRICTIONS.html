3. Blocked Phone Numbers (check.blocked.numbers)

File: app/Http/Middleware/CheckedBlockedNumbersMiddleware.php
Data table: blocked_numbers
Model: App\Models\BlockedNumber

When it applies

  • Checks phone + payment_method against the blocked_numbers table.
  • JazzCash: Skipped when config blocked_numbers.php → jazzcash_blocking_enabled is false (current default in repo).
  • Easypaisa: Always checked by middleware.

Block conditions

A request is rejected when a matching record exists AND either is_permanent = true OR block_until is in the future.

On blocked attempt

  1. Returns HTTP 400: This number is currently blocked. Please try again later.
  2. Creates a failed transaction with status = blocked (if user is resolved)
  3. Increments attempt counters on the blocked record
  4. Escalates block duration:
Attempt countBlock duration
124 hours
2–37 days
4+Permanent

6. Phone Verification Gate (phone.verified)

File: app/Http/Middleware/EnsurePhoneIsVerified.php
Service: App\Services\PhoneVerificationService
Config: config/phone_verification.php

  • Only when payment_method = easypaisa (JazzCash skips this middleware)
  • Bypass if new_user_verification = false on merchant
  • Bypass if phone already verified
  • Bypass if amount ≤ new_user_max_amount for unverified phones
  • Concurrent lock: 5 seconds per phone — HTTP 429 if busy
  • Unverified + amount over limit → HTTP 200 with status: new_user (checkout stops)

7. Per-Merchant Transaction Amount Range (restrict.user.transaction.range)

File: app/Http/Middleware/RestrictUserTransactionRange.php

  • Only for user_role = Client with transaction_limit_enabled = true
  • Uses transaction_amount_min and transaction_amount_max (min ≥ 1, max ≤ 50,000, min < max)
  • For Easypaisa + new_user_verification: only applies if phone is verified
